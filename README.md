📚 Sistema de Biblioteca

Projeto desenvolvido em Java com o objetivo de praticar e consolidar conceitos de Programação Orientada a Objetos (POO).

🎯 Objetivo

Desenvolver um sistema simples de gerenciamento de uma biblioteca, permitindo trabalhar com usuários, bibliotecários, livros e empréstimos.

O projeto foi desenvolvido como prática dos conteúdos estudados no curso de Java.

🏗️ Estrutura do projeto

O sistema é composto pelas seguintes classes e estruturas:

Pessoa — classe abstrata base para as pessoas do sistema.
Usuario — representa os usuários da biblioteca.
Bibliotecario — representa os funcionários da biblioteca.
Livro — representa os livros disponíveis para empréstimo.
Emprestimo — controla os empréstimos realizados.
Biblioteca — gerencia livros e pessoas.
Emprestavel — interface responsável pelas operações de empréstimo e devolução.
TipoLivro — enum com os tipos de livros.
StatusEmprestimo — enum com os status dos empréstimos.
Main — classe responsável pela execução e testes do sistema.
